Skeuomorphism Specification Reference Guide

Design manual, tactile physics rules, and CSS blueprints for crafting authentic physical interfaces.

1. Lighting & Edge Physics (The "Top-Down" Law)

In the real world, light almost universally comes from above. Every skeuomorphic element must obey this singular light source:

  • Top Border Highlight: Always add a 1px bright specular line to simulate light hitting the top edge (inset 0 1px 0 rgba(255,255,255, 0.2-0.4)).
  • Bottom Border Shadow: The base edge is in shadow (inset 0 -1px 0 rgba(0,0,0, 0.4-0.6)).
  • Convex Surface: Gradients must transition from lighter at the top to darker at the bottom.
  • Concave / Inset Surface: Reverse the gradient and flip the shadows to create depth inward.

3. Master CSS Code Snippets

Copy and reuse these foundational layers directly into your stylesheets:

A. Raised Convex Button State:

/* Raised Surface with Bevel Highlight */ background: linear-gradient(180deg, #4f5563 0%, #2b2e36 100%); box-shadow: inset 0 1px 0 rgba(255, 255, 255, 0.35), /* Top specular highlight */ inset 0 -1px 0 rgba(0, 0, 0, 0.4), /* Bottom chamfer shadow */ 0 4px 6px rgba(0, 0, 0, 0.4); /* Ambient drop shadow */

B. Pressed / Sunken Input Well State:

/* Sunken Display or Inset Input */ background: #18191c; box-shadow: inset 0 3px 6px rgba(0, 0, 0, 0.7), /* Deep inner shadow top */ inset 0 1px 2px rgba(0, 0, 0, 0.9), /* Tight inner cavity */ 0 1px 0 rgba(255, 255, 255, 0.08); /* Lower bottom reflection */

4. Skeuomorphism vs. Neumorphism: Key Differences

When building forward, do not confuse Skeuomorphism with Neumorphism:

  • Neumorphism (Soft UI): Minimalistic, monochromatic, uses soft matching background colors with pale dual shadows (one light, one dark). It rarely uses distinct textures or material boundaries.
  • True Skeuomorphism: Utilizes distinct physical materials (aluminum, brushed steel, plastic, leather, glass), crisp multi-step bevels, realistic tactile depression depths, and rich color contrast.
