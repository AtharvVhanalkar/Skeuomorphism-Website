Skeuomorphism Architecture Guide

Theoretical foundations, light ray directions, and implementation tokens

1. Directional Light & Edge Law

Physical skeuomorphic interfaces simulate real matter reacting to light. Light consistently comes from 90° overhead:

  • Top Rim (Specular Highlight): inset 0 1px 0 rgba(255, 255, 255, 0.38)
  • Bottom Bevel (Shadow): inset 0 -1px 0 rgba(0, 0, 0, 0.6)
  • Contact Drop Shadow: Layered ambient occlusion using multiple drop-shadow stops.

3. Skeuomorphism vs Neumorphism

Unlike Neumorphism (which blends items monochromatically with identical background shadows), Skeuomorphism creates distinct physical materials (aluminum, dark slate, incandescent lamps, physical relays) and mechanical action feedback.
